Privacy Policy

Last updated: April 13, 2026

Overview

This app is a WhatsApp-based conversational agent that enables users to log and retrieve personal memories through text, voice, and image messages. The agent processes incoming messages, extracts and stores information, and responds contextually based on previously stored data. Authorized users can interact with stored user profiles through a trigger-based session system within the same WhatsApp interface.

Data Collection and Use

This app collects and stores the text messages, voice transcriptions, and image descriptions that users choose to share through the WhatsApp interface. This data is used solely to provide the memory logging and retrieval functionality of the application.

Data Sharing

We do not sell, share, or distribute user data to third parties. Media files and conversation history are stored securely and are only accessible to the account holder.

Data Deletion

Users may request deletion of their data at any time by contacting selindursuns@gmail.com.

Research Phase

This service is currently in a research and development phase with a limited number of users.
